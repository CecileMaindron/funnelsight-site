# Funnelsight — Content Memory

Every page published on funnelsight.dev, one line per page. n8n injects this file into every generation call so Claude can detect duplicates and cannibalization risks, and pick relevant internal links.

Format: `slug | title (<title> tag) | page_type | target_audience | keywords | search_intent | hierarchical_position | internal_linking | status`

`title` is the page's `<title>` tag (SEO-facing). It can differ from the on-page H1: some playbooks use a shorter H1 without the audience qualifier, while `<title>` keeps the full keyword phrase.

`internal_linking` reflects the links actually present in each page's article body, plus its read-next block:
- `→` lists the pages this page links to. The read-next target is marked `(read-next)`. Every content page has exactly one.
- `←` lists the pages that link to this page. `(missing return link opportunity)` means that page links here, but this page doesn't link back.
- Global navigation, breadcrumb and footer links are not listed, except where noted.

Possible values for `hierarchical_position`:
- `pillar` — core page, captures the generic/brand intent
- `hub` — distribution page toward specialized content (lists, organizes, doesn't target a specific keyword)
- `cluster` — satellite page targeting a precise search intent, links up to the hub/pillar
- `utility` — functional page (conversion, form...), outside SEO targeting
- `off-flow` — page that doesn't belong to any of the page families defined in funnelsight-page-template.md (e.g. the solution pages). Listed so duplicate and cannibalization checks still cover it. Not counted in the page count below.
